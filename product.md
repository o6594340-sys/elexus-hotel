# Product: StayGuide — Hotel Guest Experience Platform
*Версия 2.0 | май 2026 | Обновлено после критического разбора*

---

## Концепция одной фразой

**PWA-приложение для гостей и MICE-делегатов отеля:** вся информация и все действия — заказать полотенца, забронировать спа, посмотреть программу мероприятия — без звонков на ресепшен, без скачивания, на любом языке.

---

## Стратегия: MICE First

**Пересмотрено после критики:**
MICE-модуль — основной продукт, Guest App — в комплекте.

**Почему:**
- Только **4% гостей** используют hotel app для общения vs **60%** предпочитают WhatsApp
- MICE-боль конкретна и измерима: программа устарела = срыв мероприятия
- MICE ROI очевиден: 100% делегатов с актуальной программой — это аргумент, который закрывает сделку
- Продавать MICE-директору проще, чем убеждать GM сократить звонки на ресепшен

**Новая логика продажи:**
1. MICE-модуль → MICE-директор или организатор тура (у него дедлайн и конкретная боль)
2. Guest App → идёт в комплекте или дешёвый Starter
3. После сезона → апсейл на полный пакет

## Функциональные требования

### 5.1 Гостевая часть

#### P0 — MVP

**Главный экран — «Что я могу сделать прямо сейчас»**

> ⚠️ Изменено после критики: главный экран — не "Сегодня в отеле", а действия.
> Данные: 50% гостей заказывают room service цифровым способом, 39% используют чатбот для простых вопросов — гости хотят действовать, а не читать.

- Быстрые кнопки: Заказать полотенца / Забронировать спа / Wi-Fi пароль / Позвонить на ресепшен
- Программа сегодняшнего дня (вторичная, под кнопками)
- Срочные уведомления (бассейн закрыт, изменение расписания)

**Рестораны и бары**
- Список всех точек с фото
- Часы работы, дресс-код, нужна ли резервация
- Что входит в пакет, что платно — явно и понятно
- Меню (PDF или структурированное)

**Что включено в пакет**
- Breakdown: бесплатно / платно / лимиты — по каждой точке и услуге
- Закрывает самую частую жалобу Elexus и турецких курортов

**Карта отеля**
- Статичная с точками интереса
- Бассейны, рестораны, спа, ресепшен, пляж, клуб, парковка

**Спа и активности**
- Описание услуг, цены, часы
- Кнопка «Записаться» — запрос без PMS-интеграции

**Запросы гостя**
- Хаускипинг: полотенца, уборка, принадлежности
- Ресепшен: общий запрос
- Room service: базовая форма
- История запросов с подтверждением статуса

**Мультиязычность**
- RU, EN, TR, AR — старт
- Переключатель на всех экранах

**PWA-доступ**
- QR-код → браузер, без App Store
- Aggressive offline cache при первом открытии (все тексты, расписание, карта)
- При первом открытии — баннер «Добавить на главный экран» с инструкцией (iOS + Android)

> ⚠️ Push-уведомления: iOS < 16.4 не поддерживает Web Push. Дублировать критичные уведомления через WhatsApp-сообщение от отеля.

#### P1 — После MVP

**MICE-модуль** *(основной тариф, не надстройка)*
- Создание мероприятия: название, даты, логотип организатора
- Программа по дням: сессии, время, зал, спикер, описание
- Live-редактирование с мгновенным обновлением у всех делегатов
- Push-уведомления при изменениях (+ WhatsApp-дубль для iOS)
- Групповые объявления от организатора всем участникам
- Отдельный QR для группы (изолирован от общего guest app)
- Мультиязычная программа (каждый делегат — на своём языке)

**Push-уведомления**
- Изменение расписания
- Анонсы вечерних шоу
- Напоминания о бронированиях
- Срочные оповещения

**Расписание анимации и шоу**
- Программа на неделю вперёд
- Фильтр: детское / взрослое / вечернее

**FAQ**
- 30–50 самых частых вопросов с ответами
- Поиск по ключевым словам
- Снимает 30–40% нагрузки с ресепшен

**Информация о локации**
- Полезные места рядом, трансфер, экскурсии

#### P2 — Следующая версия

- AI-чатбот с эскалацией к персоналу
- Оценка сервиса после посещения (service recovery до публичного отзыва)
- Личный кабинет гостя со счётом
- Интеграция с PMS (Opera, Protel, Fidelio)
- Аналитика: топ запросов, охват, снижение нагрузки на ресепшен

### 5.2 Административная панель (CMS для отеля)

#### P0

**Редактирование контента**
- Все разделы: тексты, фото, часы работы, меню
- Управление расписанием дня
- Публикация срочного уведомления за 1 клик
- Включить / выключить любой раздел

**Управление контентом — антиустаревание**

> ⚠️ Добавлено после критики: устаревший контент хуже отсутствия app. Если в app написано "открыто" а ресторан закрыт — это конфликт гостя с персоналом.

- **Ежедневное напоминание** в 08:00: "Обновите программу на сегодня" (email или SMS менеджеру)
- **Шаблоны событий**: менеджер выбирает из библиотеки (анимация, шоу, DJ-вечер, детская программа) — не пишет заново
- **Алерт для GM**: если контент не обновлялся более 24 часов — уведомление
- **Импорт расписания**: загрузить Excel или подключить Google Calendar отеля

**Запросы гостей**
- Входящие запросы с уведомлением (хаускипинг, ресепшен, room service)
- Смена статуса: Новый / В работе / Выполнен
- Гость видит статус в реальном времени

**Мультиязычность**
- Управление переводами по каждому разделу
- Включить/выключить языки

#### P1

**MICE-панель**
- Создание и редактирование мероприятий
- Отправка групповых объявлений
- Аналитика: охват делегатов, просмотры программы

**ROI-калькулятор для продаж**

> ⚠️ Добавлено после критики: 43% отелей не могут посчитать ROI от технологий — это главный стоп-фактор для подписания контракта.

- Менеджер отеля вводит: кол-во номеров, среднее кол-во типовых звонков в день, стоимость часа сотрудника
- Получает: "Вы экономите X часов/мес = €Y/мес"
- Сравнение с ценой подписки → наглядный ROI

**Аналитика**
- Самые просматриваемые разделы
- Топ запросов гостей
- Динамика охвата

## Технический стек

| Слой | Технология | Обоснование |
|---|---|---|
| Frontend / PWA | Next.js + Tailwind CSS | Быстро, offline-ready, знакомый стек |
| Backend / БД | Supabase | Realtime, auth, storage, бесплатный старт |
| Push-уведомления | Web Push API | Работает без native app (Android + iOS 16.4+) |
| Дублирование push | WhatsApp Business API | Для iOS < 16.4 и критичных уведомлений |
| Хостинг | Vercel | Deploy за минуты |
| Мультиязычность | next-i18next | Стандарт для Next.js |
| Изображения | Supabase Storage | |
| Аналитика | Plausible | Без cookie-баннеров |

**Архитектура:**
- Один Next.js проект, мультитенантность через subdomain (`elexus.stayguide.app`)
- Данные изолированы через Supabase RLS
- CMS — роут `/admin` с авторизацией
- Service Worker: offline-first, кэш при первом открытии

## Дизайн

**Стиль:** современный, тёплый, курортный. Не корпоративный.

**Принципы:**
- Action-first: крупные кнопки действий на главном экране
- Фото на первом плане — отель продаёт картинкой
- Никаких длинных списков — карточки с превью
- Навигация через большие иконки (пальцы на телефоне у бассейна)
- White-label: логотип отеля, основной цвет бренда

**UX-онбординг при первом открытии:**
1. Приветственный экран с логотипом отеля
2. Выбор языка
3. Баннер "Добавить на главный экран" — с анимированной инструкцией
4. Главный экран с действиями

## Что НЕ входит в MVP

- Интеграция с PMS — P2 после первых клиентов
- Mobile key / Bluetooth — только native app, не наша история
- Онлайн-оплата внутри app — юридическая сложность
- AI-чатбот — P2, интегрировать готовое решение позже
- Native iOS/Android app — только PWA на старте
