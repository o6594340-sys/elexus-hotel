# Brief: StayGuide — Hotel Guest Experience Platform
*Версия 2.0 | май 2026 | Обновлено после критического разбора*

---

## 1. Суть продукта

**StayGuide** — PWA-приложение для гостей и MICE-делегатов отеля. Открывается по QR-коду в браузере без скачивания. Позволяет совершать действия (заказать полотенца, забронировать спа, узнать пароль Wi-Fi) и находить информацию (расписание, рестораны, что включено) — на любом языке, в любое время.

Два режима в одной платформе:
- **MICE-модуль** — цифровая программа мероприятия с live-обновлениями для корпоративных групп *(основной продукт)*
- **Guest App** — информационный гид для индивидуальных гостей *(в комплекте или отдельно)*

Продаётся отелям как SaaS по подписке. White-label — каждый отель со своим брендом.

## 2. Стратегия: MICE First

> ⚠️ Пересмотрено после критического разбора

**Прежняя логика:** Guest App — основной продукт, MICE — надстройка.

**Новая логика:** MICE-модуль — основной продукт, Guest App — в комплекте.

**Почему изменили:**
- Только **4% гостей** используют hotel app для коммуникации; **60%** предпочитают WhatsApp — информационный guest app сложно продать через ROI
- MICE-боль конкретна и измерима: программа устарела = реальный срыв мероприятия
- MICE-директор принимает решение быстрее, у него жёсткий дедлайн
- Ни один конкурент не закрыл эту нишу достаточно хорошо

**Новая воронка продажи:**
1. Продаём MICE-модуль → MICE-директору отеля или организатору тура
2. Guest App — "в комплекте" к MICE-подписке
3. После сезона → апсейл на Business/Enterprise с полным функционалом

## 3. Проблема

### Для гостей
Гость заезжает и не знает: что входит в пакет, когда работает ресторан, что происходит вечером, как заказать полотенца. Единственный способ — позвонить на ресепшен или дойти лично.

**Реальные цитаты из TripAdvisor:**
- Elexus: *"All Inclusive Plus только в главном ресторане — нигде не написано"*
- Elexus: *"Сидели у бассейна в темноте — никто не сказал, что освещение не работает"*
- Rixos: *"Promised via WhatsApp — came to checkout and nothing was organised"*
- Susesi: *"Had extra charges we didn't know about"*

### Для MICE-групп
- Программа мероприятия меняется — бумажные буклеты устарели в момент печати
- Организатор звонит менеджеру отеля десятки раз в день
- Делегаты опаздывают, теряют программы, не понимают где что

**Реальный пример:** IMWF 2025, Regnum Carya — делегаты из 90+ стран, бумажные программы, языковой барьер.

### Для отеля
- Ресепшен перегружен: оценочно 200–300 типовых звонков в смену в крупном отеле
- Информационный пробел → плохие отзывы → падение рейтинга TripAdvisor
- Устаревший контент в цифровых каналах — конфликт гостя с персоналом

3. **PWA без скачивания** — QR → браузер, барьер = ноль
4. **Умный CMS** — напоминания, шаблоны, алерт устаревания
5. **RU-контент** — козырь на рынке СНГ-туристов
6. **Standalone без PMS** — главный страх отелей снят

## 6. Функциональные требования

### 6.1 Гостевая часть

#### P0 — MVP

**Главный экран — «Что я могу сделать прямо сейчас»**
> Изменено: не информационный экран, а экран действий. 50% гостей хотят digital room service, 39% — digital ответы на вопросы.

- Быстрые кнопки: Полотенца / Спа / Wi-Fi / Ресепшен
- Программа сегодняшнего дня
- Срочные уведомления отеля

**Рестораны и бары**
- Список с фото, часы, дресс-код, резервация
- Что входит в пакет, что платно — явно

**Что включено в пакет**
- Наглядный breakdown по каждой точке и услуге

**Карта отеля**
- Статичная с ключевыми точками

**Спа и активности**
- Описание, цены, часы, кнопка запроса записи

**Запросы гостя с историей**
- Хаускипинг, ресепшен, room service
- Статус запроса в реальном времени (Принят / В работе / Выполнен)

**Мультиязычность:** RU, EN, TR, AR

**PWA-онбординг:**
- QR → браузер без App Store
- Aggressive offline cache при первом открытии
- Баннер «Добавить на главный экран» с анимированной инструкцией
- Push: Web Push API (Android + iOS 16.4+); критичные — дублировать через WhatsApp

#### P1 — После MVP

**MICE-модуль**
- Создание мероприятия с брендом организатора
- Программа по дням: сессии, время, зал, спикер
- Live-редактирование → мгновенное обновление у всех делегатов
- Push при изменениях + WhatsApp-дубль
- Групповые объявления от организатора
- Отдельный QR для группы
- Мультиязычная программа

**Push-уведомления** (анонсы, напоминания, изменения)

**Расписание анимации** (неделя вперёд, фильтры)

**FAQ** (30–50 вопросов, поиск)

#### P2 — Следующая версия
AI-чатбот, оценка сервиса, кабинет гостя, PMS-интеграция, аналитика

### 6.2 Административная панель (CMS)

#### P0

**Редактирование контента**
- Все разделы: тексты, фото, часы, меню
- Расписание дня, уведомления, включить/выключить разделы

**Антиустаревание контента**
> Добавлено: устаревший контент = конфликт гость vs персонал. Хуже, чем отсутствие app.

- Ежедневное напоминание в 08:00 менеджеру: "Обновите программу"
- Библиотека шаблонов событий (выбрать из списка, не писать заново)
- Алерт GM: контент не обновлялся более 24 часов
- Импорт расписания из Excel или Google Calendar

**Запросы гостей**
- Входящие с уведомлением
- Статусы: Новый / В работе / Выполнен
- Гость видит статус в реальном времени

#### P1

**MICE-панель**
- Создание/редактирование мероприятий
- Групповые объявления
- Аналитика: охват делегатов

**ROI-калькулятор**
> Добавлено: 43% отелей не могут обосновать ROI. Это главный стоп-фактор сделки.

- Ввод: кол-во номеров + типовых звонков в день + стоимость часа сотрудника
- Вывод: экономия €X/мес при подписке €Y/мес
- Встроен в CMS и в продажный питч

## 8. Дизайн

**Концепция:** luxury hospitality — тёмно-синий + золото + кремовый. Не корпоративный, не детский. Ближайший аналог: мобильное приложение бутик-отеля 5★.

### Дизайн-система (реализована май 2026)

**Цветовая палитра:**
| Токен | Hex | Применение |
|---|---|---|
| `--color-navy` | `#0c1824` | Хедер, основной текст, иконки |
| `--color-gold` | `#c9a96e` | Акцент — строго в 3 местах максимум |
| `--color-cream` | `#faf9f6` | Фон страниц |
| `--color-muted` | `#8a9099` | Вторичный текст |

**Типографика:**
- **Playfair Display** (`font-display`) — название отеля, заголовки разделов. Дает ощущение класса и elegance.
- **DM Sans** (`font-sans`) — всё тело. Читабельный, современный, не технический.
- Размеры: headline 28–34px / section 18–20px / body 14–16px / caption 12px / nav 10px uppercase

**Иконки:** SVG везде. Emoji запрещены — выдают дешевизну.

**Ключевые UI-паттерны:**
- Action buttons: белые карточки, navy SVG-иконка, золотая граница при нажатии
- Модалки: bottom sheet (не центр экрана) с drag handle
- Расписание: timeline с временем в отдельной колонке и цветными тегами категорий
- Анонсы: золотая левая граница 3px на кремовом фоне
- Nav: SVG-иконки, gold = активный таб

**Анимации:** медленные и намеренные (400–600ms ease-out). Luxury двигается медленно.

**Правила реализации:**
- Hover только через CSS `:hover` / `:active`, не `onMouseEnter` (это PWA — touch)
- Все цвета через CSS-переменные в `@theme`, не захардкоженные hex (white-label!)
- Модалки через `createPortal` в `document.body`
- `aria-hidden="true"` на декоративных SVG

### Оценка дизайна (специалисты, май 2026)

| Критерий | Оценка | Комментарий |
|---|---|---|
| Visual Design | 6.5/10 | Палитра и типографика верные, execution осторожный |
| UX Flow | 6/10 | Action-кнопки плоские по иерархии, hover на мобильном не работает |
| Luxury Feel | 5.5/10 | Читается как "premium boutique", не 5★ resort |
| Code Quality | 4/10 | Inline styles обходят Tailwind @theme |
| Accessibility | 3/10 | Контраст, модалка без role=dialog, фокус-ловушки |

**Главное что нужно улучшить:**
1. Hero с фото отеля (сейчас plain navy — нет WOW-момента)
2. Типографика крупнее (аудитория 45+ на солнце)
3. Золото убрать из 4 из 7 мест (должно быть scarce)
4. Inline styles → Tailwind-токены (требует white-label)
5. Wi-Fi модал → настоящий `role="dialog"` с focus trap

**Что хорошо:** выбор Playfair Display + DM Sans + отказ от emoji — правильный фундамент.

### UX-онбординг (первое открытие)
1. Hero с фото отеля (закат над бассейном + overlay)
2. Золотой eyebrow "WELCOME" + Playfair Display название
3. Action-кнопки без лишнего текста
4. Баннер "Добавить на главный экран" (анимированная инструкция)

## 11. Стратегия продаж

### Временная линия (реалистичная)
- **Май 2026** — выставка в Elexus: знакомство, сбор контактов, демо
