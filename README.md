# StayGuide — Hotel Guest Experience Platform

PWA-приложение для гостей и MICE-делегатов отеля. Открывается по QR-коду без скачивания.

## Что делает продукт

Гость сканирует QR-код в номере → открывает браузер → видит всё об отеле и может сразу действовать: заказать полотенца, забронировать спа, узнать расписание, написать на ресепшен. Без скачивания. На своём языке.

Для корпоративных групп — live-программа мероприятия с мгновенными обновлениями.

---

## Два продукта в одной платформе

### MICE-модуль *(основной)*
- Цифровая программа мероприятия с брендом организатора
- Live-обновления — делегаты видят изменения мгновенно
- Групповые объявления от организатора
- Отдельный QR для группы
- Мультиязычная программа

### Guest App *(в комплекте)*
- Action-first главный экран: полотенца, спа, Wi-Fi, ресепшен
- Рестораны и бары: часы, меню, что включено в пакет
- Карта отеля, спа и активности
- Запросы с отслеживанием статуса
- Программа дня, анонсы, уведомления

## Ключевые продуктовые решения

**Почему action-first, а не информационный экран:**
Только 4% гостей используют hotel app для коммуникации. 50% хотят digital room service. Гости не читают — они действуют.

**Почему PWA, а не native app:**
Гости не скачивают hotel apps (только 19%). QR → браузер → мгновенный доступ.

**Почему MICE first:**
MICE-боль конкретна и измерима. ROI очевиден. Ни один конкурент не закрыл эту нишу хорошо.

**Почему без PMS-интеграции на старте:**
69% отелей называют интеграцию главным барьером. Standalone = ниже порог входа.
